Como configurar
1 — Criar a planilha Google
  1. Acesse sheets.google.com e crie uma planilha em branco
  2. O ID é a parte da URL entre /d/ e /edit
2 — Instalar o Apps Script (backend)
  1. Na planilha: Extensões → Apps Script
  2. Apague o código existente e cole o conteúdo do arquivo apps_script.gs
  3. Salve (Ctrl+S) e clique em Executar → inicializarPlanilha uma vez para criar as abas
  4. Implantar → Nova implantação → Tipo: Aplicativo da Web
  5. Executar como: Eu · Acesso: Qualquer pessoa → Implantar → Autorizar
  6. Copie a URL do aplicativo web
A URL começa com https://script.google.com/macros/s/
Senha inicial padrão: admin1234
